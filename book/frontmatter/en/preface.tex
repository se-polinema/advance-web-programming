\chapter*{Preface}
\addcontentsline{toc}{chapter}{Preface}

\noindent
This book is written for readers who want to build a web application people
actually use, not just follow a string of disconnected tutorials. The material
moves from the basics of web architecture and the MVC pattern, through
databases and Eloquent, and stops at a point most beginner programming books
skip: security, data reporting, and a REST API ready for another application
to consume.

\vspace{1cm}

\noindent
One application, a simple point-of-sale system, runs through nearly every
chapter. Concepts that sound abstract, such as validation, authorization, or
eager loading, always rest on a concrete feature: recording a transaction,
locking stock while a sale is in progress, or restricting a report page to
admins only.

\vspace{1cm}

\noindent
