\chapter*{Kata Pengantar}
\addcontentsline{toc}{chapter}{Kata Pengantar}

\noindent
Buku ini disusun untuk pembaca yang ingin membangun aplikasi web yang benar-benar
dipakai, bukan sekadar mengikuti tutorial terputus-putus. Materinya bergerak dari
konsep dasar arsitektur web dan pola MVC, melewati basis data dan Eloquent,
lalu berhenti di titik yang jarang disentuh buku pemrograman pemula: keamanan,
pelaporan data, dan REST API yang siap dipakai aplikasi lain.

\vspace{1cm}

\noindent
Satu aplikasi yang sama, sebuah sistem kasir sederhana, menemani hampir setiap
bab. Konsep yang terasa abstrak seperti validasi, otorisasi, atau eager loading
selalu berpijak pada fitur nyata: mencatat transaksi, mengunci stok saat
penjualan berlangsung, atau membatasi akses laporan hanya untuk admin.
